# FG0009: Input interface required

## Cause
Method uses Funge input instructions but has no input mechanism defined.

## Solution
Add an input parameter (string, TextReader, or PipeReader).

## Example

```cs
partial class Sample
{
    // Incorrect: requires input but no input mechanism
    [GenerateFungeMethod(InlineSource = ",@")]
    public static partial void Invalid();
}
```
