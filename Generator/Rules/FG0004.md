# FG0004: Funge source file not found

## Cause
The Funge source file path provided to the `GenerateFungeMethodAttribute` cannot be resolved.

## Solution
Ensure the source file exists and is correctly referenced in the project's `AdditionalFiles`.

## Example

```cs
partial class Sample
{
    // Incorrect: "nonexistent.b98" is not found
    [GenerateFungeMethod("nonexistent.b98")]
    public static partial void Invalid();
}
```
