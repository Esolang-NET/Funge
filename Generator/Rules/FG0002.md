# FG0002: Unsupported return type

## Cause
The method's return type is not supported by the Funge source generator.

## Solution
Change the return type to one of the supported types (e.g., `void`, `int`, `string`, `Task`, `ValueTask`, `IEnumerable<byte>`, `IAsyncEnumerable<byte>`).

## Example

```cs
partial class Sample
{
    // Incorrect: double is not a supported return type
    [GenerateFungeMethod(InlineSource = ">@")]
    public static partial double Invalid();
}
```
