# FG0007: Return type and output parameter conflict

## Cause
Method has both return-based output and an output parameter (TextWriter/PipeWriter).

## Solution
Use one or the other, not both.

## Example

```cs
partial class Sample
{
    // Incorrect: string return and TextWriter output parameter conflict
    [GenerateFungeMethod(InlineSource = ".@")]
    public static partial string Invalid(System.IO.TextWriter output);
}
```
