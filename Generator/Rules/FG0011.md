# FG0011: Method must be partial

## Cause
The method decorated with `GenerateFungeMethodAttribute` is not declared with the `partial` modifier.

## Solution
Add the `partial` modifier to the method definition.

## Example

```cs
partial class Sample
{
    // Incorrect: not partial
    [GenerateFungeMethod(InlineSource = ">@")]
    public void Invalid();
}
```
