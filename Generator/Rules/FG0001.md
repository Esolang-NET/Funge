# FG0001: Invalid source path parameter

## Cause
The `sourcePath` provided to the `GenerateFungeMethodAttribute` is null or empty.

## Solution
Ensure a valid, non-empty source path or inline source is provided to the attribute.

## Example

```cs
partial class Sample
{
    // Incorrect: Missing or empty source
    [GenerateFungeMethod("")]
    public static partial void Invalid();
}
```
