# FG0010: Unused input interface

## Cause
Method has an input parameter but the Funge source does not use any input instructions.

## Solution
Remove the unused input parameter.

## Example

```cs
partial class Sample
{
    // Incorrect: input instruction not used
    [GenerateFungeMethod(InlineSource = ">@")]
    public static partial void Invalid(string input);
}
```
