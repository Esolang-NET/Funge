# FG0008: Output interface required

## Cause
Method uses Funge output instructions but has no output mechanism defined.

## Solution
Add a return type (string/IEnumerable&lt;byte&gt;) or a TextWriter/PipeWriter parameter.

## Example

```cs
partial class Sample
{
    // Incorrect: requires output but no output mechanism
    [GenerateFungeMethod(InlineSource = ".@")]
    public static partial void Invalid();
}
```
